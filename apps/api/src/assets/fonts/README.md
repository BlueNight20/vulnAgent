# Report font

VulnAgentReportSans.ttf is a regular-weight (wght=400) static instance of Noto Sans SC from
https://github.com/google/fonts/tree/main/ofl/notosanssc (downloaded 2026-11-02).
Redistributed under the accompanying OFL.txt (SIL Open Font License 1.1).
It is renamed as VulnAgent Report Sans and generated using scripts/prepare-report-font.py.
The font remains under SIL OFL 1.1. Copyright notices are preserved in its metadata.
It is bundled with the API build so PDF exports work offline on Windows and Linux.
